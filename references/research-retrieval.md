# Research Retrieval

Use for broad field research, source coverage, recommendations, or frontier reconstruction.

## Coverage before conclusions

- Prefer primary or authoritative sources.
- Distinguish frontier anchors from keyword-related results.
- Do not infer field-wide conclusions from a handful of papers, repositories, search results, or summaries.
- Do not substitute an easier adjacent field for the user's specified technical subfield.
- When coverage is incomplete, narrow the conclusion instead of filling gaps by inference.

Search ranking is not a quality ranking.

## Source-quality order

Prefer:

1. original/seminal method papers and strongest direct theoretical work;
2. recent strong descendants that materially extend the mechanism;
3. direct prior work in the target problem;
4. papers that clearly expose current limitations/bottlenecks;
5. high-quality reviews for map-building;
6. generic application papers only as coverage/negative evidence.

## Frontier reconstruction

For method/domain A, establish:
- object;
- mechanism;
- assumptions;
- strongest known capability;
- failure boundary;
- key author/citation lineage.

For target domain B, establish:
- concrete unresolved bottlenecks;
- why current approaches fail;
- structural cause of failure;
- evidence that would count as meaningful progress.

Only then form mechanism-to-bottleneck matches.

## Recommendation discipline

Before ranking or recommending options, verify:
- candidate-set coverage is adequate for the requested scope;
- required resources/constraints are actually satisfied;
- ranking criterion matches the user's criterion;
- facts are current when freshness matters.

If coverage is incomplete, report the inspected scope and avoid an overall ranking.
